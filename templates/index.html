🐱 캬루:
📘 앱 사용 방법
  • 닉네임을 먼저 입력한 후, 현재 상태를 선택하세요.
  • 복귀 시간이 필요한 경우, 상태 선택 전에 분 단위로 시간을 설정하면 자동 타이머가 시작됩니다.
  • 빠른 상태 버튼을 누르면 디스코드에 현재 상태와 복귀 예정 시각이 전송됩니다.
  • 상태 진행 중에는 타이머 연장 버튼을 통해 복귀 시간을 추가로 늘릴 수 있습니다.
  • 복귀 버튼을 누르면 즉시 상태가 종료되며, 자동 복귀 타이머도 함께 해제됩니다.
⏱ 타이머 기능 사용 시 주의사항
  • 타이머는 브라우저에 저장되며, 같은 브라우저에서만 상태 복구가 가능합니다.
  • 브라우저를 완전히 종료하거나 저장 데이터가 삭제되면 타이머 정보가 사라질 수 있습니다.
  • 복귀 시간이 지난 상태에서 연장할 경우, 연장은 현재 시점을 기준으로 다시 계산됩니다.
  • 자동 복귀 시에도 디스코드로 복귀 상태가 전송되며, 알림 권한이 허용된 경우 알림이 표시됩니다.
  • 네트워크 상태에 따라 디스코드 메시지 전송이 지연되거나 실패할 수 있습니다.
⏱ 알람 사용과 쿠키에 대해
  • 창 유지 필수: 타이머는 브라우저 엔진에서 돌아가요. 창을 완전히 닫거나 컴퓨터가 절전 모드에 들어가면 자동 복귀 기능이 멈출 수 있으니 주의해 주세요!
  • 새로고침 안심: 다행히 새로고침을 하거나 실수로 창을 잠시 닫아도, 기존에 설정한 타이머는 로컬 저장소 덕분에 자동으로 복구됩니다.
  • 알림 허용: 타이머가 끝났을 때 알림을 받고 싶다면, 브라우저 주소창 왼쪽의 자물쇠 아이콘을 눌러 '알림 권한'을 꼭 허용해 주세요.
