📘 전체 사용 설명서

⏱ 타이머 & 상태 설정
  • 닉네임 입력 후 상태 버튼을 누르면 디스코드에 즉시 전송된다고! 진짜 좋지?
  • 시간을 선택하면 자동 복귀 타이머가 작동해! 켜두기만 해도 자동으로 시간이 감지돼!
  • 잠수모드 버튼을 누르면 60분동안 마우스 움직임이나 키보드를 입력하지 않으면 자동으로 잠수한다고 메세지를 보낼거야!
  • 이미 '밥'이나 '외출' 등을 직접 설정했다면, 시간이 지나도 '잠수' 상태로 덮어쓰지 않으니까 걱정말라구!
  • 브라우저를 최소화하면 감지가 안 될 수 있으니, 창을 띄워두거나 다른 창 뒤에 숨겨둬!
  • 게임 중 돌아왔다면 알라미 브라우저 창을 한 번 클릭해야 마우스 움직임이 인식되니까 주의하라고!
